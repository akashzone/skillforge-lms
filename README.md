# SkillForge LMS

A MERN stack Learning Management System where instructors can create courses and students can enroll and track their learning progress.

## Tech Stack

- React
- Node.js
- Express.js
- MongoDB
- Mongoose

## Status

🚧 Currently under development.

## Planned Features

- Authentication & Authorization
- Course Creation
- Student Enrollment
- Video Lectures
- Progress Tracking
- Instructor Dashboard
- Admin Dashboard
